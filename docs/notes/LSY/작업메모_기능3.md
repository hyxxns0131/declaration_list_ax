| 한 신고건 검사 | 아래면 **만들지 않음**(이유 표시, 행 체크는 유지, [생성]만 풂): 다른 신고 묶음 섞임 / 다른 모선(화물관리번호 앞 11자리) / 다른 제조사. 이미 승인번호 있는 행·빈 값은 **경고만** |

| 공장 고르기 | ① 서류 주소 ↔ 등록 공장 주소 점수(기준 0.45, 2등과 0.1 차) → ② 같은 모델 과거 신고 공장 코드 → ③ 빈칸 + 선택지. 주소로 고른 공장이 과거 코드와 다르면 "확인 필요" 메모. **A사 prefer_past_factory_code**: 과거 코드 우선, 이 경우 주소 다름 경고 안 함 |

| 개선(제안서 4번 ②) | 최대 행 수·내색·정렬 기준은 **새 설정으로 추가**, 기본값은 꺼짐(기존 동작과 같게). B사 최대 행 수 값은 PM 확인 필요(기존 실무는 담당자가 5~7행으로 합치고 7행 넘어도 안 나눔) |

## 정한 것 (11/25 추가)
| 항목 | 결정 |
|---|---|
| 공장 비교 | 해외제조업소 **코드**로 묶음. 코드 같고 이름 표기만 다르면 경고, 코드 없으면 이름으로 임시 + 확인 필요 |
| 재질 묶음 | 가나다순·중복 제거 후 **목록이 똑같을 때만** 자동으로 묶음. 포함 관계는 실적 고르기·사람이 합친 묶음 검사에서만 |
| 따로 두는 행 | 재질이 없거나 '자료 추가 필요', 화물관리번호 없음, 승인된 행은 묶지 않음 |
| B사 최대 행 수 | 끔 (설정만 둠) |
| 재질·색상 다른 행 합치기 | 허용하되 **막기 검사**: 재질 확정, 행마다 쓸 수 있는 실적, A사는 실적 하나가 모든 재질 포함. 정밀검사 대상과 실적 있는 품목 섞기는 지금 막음(확인 필요) |

## 확인 필요 (열린 질문)
- 정밀검사 대상(실적 없음) 품목과 실적 있는 품목을 한 신고에 섞어도 되는지
- 검역이력 시트의 **이름 없는 열**(실적접수번호 ↔ 영문 제품명 사이) 용도. 숨김 열이 더 있는지(시트에서 전체 숨기기 해제로 확인)
- 신고건 키: 스키마는 제조업소 **코드**, 기존 코드는 제조사 **이름** — 어느 쪽?
- B사 최대 행 수 기본값(5? 끔?)
- 실적 기산일: 운영 시트 '승인일' = 수입신고확인증 발급일인지
- 품목사항 양식: 유니패스 실제 머리글 글자·시트명(지금 '품목사항')·머리글 행 위치(지금 1행). `templates/item_sheet.xlsx`는 기존 양식 열 순서로 만든 임시본
- 영문 제품명에서 떼는 수기 표시: 지금 '정밀검사'만(`build.py` MANUAL_MARKS). 다른 표시가 있는지
- 한글 다운로드 파일명이 실제 Chrome·Edge에서 정상인지
